# ♟️ Chess960 (Шахматы-960)

## 📖 О игре
**Chess960** (Шахматы Фишера) — это вариация классических шахмат, в которой начальные позиции фигур на первой и восьмой горизонталях генерируются случайным образом (из 960 возможных комбинаций). Это исключает заучивание дебютов и делает каждую партию уникальной.

## 🎮 Режимы игры
* 🤝 **Против друг друга** — игра вдвоем на одном устройстве.
* 🤖 **Против компьютера** — игра со встроенным игровым искусственным интеллектом.
* 🌐 **Локальная сеть (LAN)** — мультиплеер с друзьями по локальной сети.

## 🚀 Как начать играть
Вам не нужно ничего компилировать! Чтобы запустить игру:
1. Перейдите в раздел **[Releases](https://github.com/Gory007/8V42_Kiegechev_TXI_Cours/releases)** этого репозитория.
2. Скачайте последнюю доступную версию для вашей операционной системы.
3. Распакуйте архив и запустите исполняемый файл.

Если вы хотите собрать проект самостоятельно, вам понадобятся **CMake** (3.10+) и **Qt 6**.
